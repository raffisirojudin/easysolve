## 📌 Tentang EasySolve
  EasySolve adalah platform edukasi berbasis web yang dirancang sebagai pusat referensi belajar siswa. Platform ini tidak hanya memberikan kunci jawaban, tetapi fokus pada penjabaran rumus dan metode penyelesaian masalah agar siswa benar-benar paham.

  ### ✨ Fitur Utama
  * **Subject Categorization:** Pengelompokan materi berdasarkan mata pelajaran seperti Matematika, Fisika, Kimia, hingga Bahasa.
  * **Formula Calculator:** Kalkulator otomatis untuk rumus-rumus tertentu (misal: Rumus Pythagoras atau Kuadrat), lengkap dengan langkahnya.
  * **Search & Filter:** Memudahkan pencarian topik atau soal tertentu menggunakan kata kunci.
  * **Bookmarks:** Fitur bagi siswa untuk menyimpan pembahasan soal penting agar bisa dipelajari kembali nanti.

  ### 🛠️ Tech Stack
  * **Core:** JavaScript (Search logic & math functions), HTML5, CSS Grid/Flexbox.
